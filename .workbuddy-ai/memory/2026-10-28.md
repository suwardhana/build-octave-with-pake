## Refactor performa + `octave-diag` (v1.2.0)

Dhana minta semua saran performa dikerjakan, dengan commit kecil-kecil. Batasan yang dia
tetapkan di tengah jalan:

- **Auto-download lossless TETAP** (internet cepat, memang mau lossless). Jangan dijadikan opt-in.
- **Hover prefetch TETAP**, tapi optimalkan kalau ada yang bisa diperbaiki.
- **Ide plugin cukup sampai `octave-diag`**; sleep timer, shortcuts, mini player, EQ, Tier 2 nanti.
- **Hapus `src/js/octave-volume.js`.**
- **Hapus tombol download floating kanan bawah.** Ternyata source sudah bersih sejak rollback
  18 Okt — tombol itu hanya ada di build lama yang terpasang. Konfirmasi: `grep -ri download src`
  tidak menemukan apa pun selain komentar warm audio.

## Yang dikerjakan

### 1. Hapus plugin volume

`src/js/octave-volume.js` dihapus, entry `inject` dibuang, bagian "Volume" di readme diganti
catatan arsip. `reference/volume.ts` tetap disimpan sebagai arsip, tidak diinject.

### 2. `octave-core.js` — fondasi bersama

- Satu `MutationObserver`: `childList` + `subtree` + `attributeFilter: ['src']`.
  **Tidak** mengamati `characterData` — ini yang dulu membuat ngetik di search / timer progres
  memicu sweep seluruh body.
- Satu route hook: patch `history.pushState`/`replaceState` + `popstate`/`hashchange`,
  debounce 30 ms, hanya dispatch kalau path berubah.
- Batch kerja via `requestIdleCallback` (fallback `setTimeout` 120 ms), skip kalau
  `document.visibilityState === 'hidden'`, lalu catch-up saat visible.
- Registry `__octave.register(id, health)`, metrics (`__octave.metric`), ring buffer error.
- Flag `perfMode` di `localStorage['__octave_flags_v1']` untuk mematikan kerja kosmetik.

### 3. Modul lama pakai core

- `octave-native.js`: observer sendiri dihapus, `WeakSet` memo, hanya macOS (Windows no-op,
  padding traffic-light tidak bocor ke Windows).
- `octave-depin.js`: observer global + `characterData` dihapus; scope hanya sidebar
  (`aside`/`nav`/`[class*=sidebar]`), sweep hanya kalau batch menyentuh sidebar.
- `octave-media.js`: dua `setInterval` (2 dtk + 1 dtk) dihapus; enforce dari event
  `play`/`pause`/`loadedmetadata`/`ended` + route. API `__octave.media` (`next`, `prev`,
  `toggle`, `seek`).
- `octave-media-lazy.js`: tidak lagi `querySelectorAll('video')` tiap mutation batch; scan
  hanya kalau ada video yang benar-benar ditambahkan / route baru.
- `octave-prefetch.js`: `<link rel=prefetch>` dihapus (dulu dobel request dengan fetch manual);
  dwell 120 ms + cek `:hover`, maksimal 2 request paralel, dedupe, hormati `saveData`.
- `disable-right-click.js`: dibungkus IIFE + guard, `document.head` fallback, guard
  `e.target.closest`.

### 4. `octave-cache.js`

- Observer global diganti langganan `octave.onMutations`.
- API memory cache dibatasi 60 entri / 8 MB + skip body > 512 KB.
- Blob URL: flag `octaveBlob` yang permanen diganti cek `octaveBlobTrack` + `octaveBlobUrl`;
  blob lama di-revoke setelah 60 dtk, plus budget 6 blob URL dan revoke saat `pagehide`.
- Cache static/cover (`warmStatic`, `CACHE_STATIC`) dihapus — redundan dengan SW situs.
- `Content-Length` ditambahkan ke Response audio yang di-cache.
- Auto-warm lossless **tidak diubah**.

### 5. `octave-diag.js`

Panel diagnostik di Shadow DOM, tombol "i" kanan bawah + `Cmd/Ctrl+Shift+D`:

- core stats, flags, storage estimate/persisted, index cache audio, cache stores/keys;
- daftar modul + health, elemen media (jenis src, durasi, posisi), `mediaSession`;
- metrics + error terakhir;
- Copy report, Refresh, toggle perf mode.

### 6. Check + CI

- `scripts/check.mjs` — 99 pemeriksaan tanpa dependency (file inject, urutan, guard, IIFE,
  `const` top-level, `node --check`, `appVersion` vs `package.json`).
- `package.json` — script `check`, `dev` (`--debug --iterative-build`), `build` (`--install`).
- Windows workflow: step `node scripts/check.mjs` sebelum build.
- macOS workflow baru: universal (Apple Silicon + Intel) di `macos-14`, publish DMG +
  `SHA256SUMS.txt`, catatan Gatekeeper.
